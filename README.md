# Portfolio personal - David Martín Prieto

Portfolio personal realizado para la práctica de 1.º DAM.

La web está hecha desde cero con HTML, CSS y JavaScript vanilla. No usa Bootstrap, Tailwind, React ni plantillas descargadas.

## URL de la página publicada

Cuando esté publicada en GitHub Pages, cambia esta línea por la URL real:

`https://d3m5p2.github.io/portfolio-david-martin-prieto/`

## Tecnologías usadas

- HTML5 semántico
- CSS3 propio
- JavaScript vanilla
- GitHub Pages
- Google Fonts
- Imagen optimizada en WebP

## Paleta de colores

- Fondo principal: `#070b18`
- Fondo secundario: `#0b1020`
- Tarjetas: `#10172a`
- Azul neón: `#00e5ff`
- Morado: `#7c3aed`
- Texto principal: `#f8fafc`
- Texto secundario: `#a8b3cf`

He elegido estos colores para darle un estilo cyberpunk oscuro, pero sin meter demasiados efectos ni animaciones complicadas.

## Elemento diferenciador

El elemento diferenciador es el diseño visual estilo cyberpunk sencillo: fondo oscuro, azul neón, tarjetas oscuras, foto destacada y secciones ordenadas.

No he querido añadir demasiadas animaciones porque es un trabajo de 1.º DAM y quiero poder explicar bien el código.

## Uso de IA

He usado IA como ayuda para organizar la estructura, mejorar el diseño y preparar parte del código. Después he personalizado el contenido con mis datos reales, mi foto, mi formación y mis proyectos.

## Dificultades encontradas

Una dificultad fue hacer una página con buen diseño sin usar Bootstrap ni frameworks. Para resolverlo he usado CSS propio, grid, flexbox y variables CSS.

También he intentado que el JavaScript sea sencillo, usando solo lo necesario para abrir y cerrar el menú móvil.
